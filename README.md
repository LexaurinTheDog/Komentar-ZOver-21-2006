# Komentář k zákonu č. 21/2006 Sb., o ověřování shody opisu nebo kopie s listinou a o ověřování pravosti podpisu a o změně některých zákonů (zákon o ověřování)

Otevřený komentář k zákonu o ověřování — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; vidimace a legalizace, ověřující úřady a subjekty, ověřovací doložka, důvody odmítnutí, legalizace elektronických dokumentů a ověřovací kniha.

Konsolidované znění: dokument e-Sbírky `SB-2006-00021_2026-01-01`.
